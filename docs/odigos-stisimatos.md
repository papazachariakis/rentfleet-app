# Οδηγός στησίματος RentFleet — βήμα βήμα

Οδηγός για **νέο ιδιοκτήτη rent-a-car** που ανοίγει λογαριασμό στο [rentfleet-app.vercel.app](https://rentfleet-app.vercel.app) και θέλει να είναι έτοιμος για πραγματικές κρατήσεις (desk + online), πληρωμές Stripe και ΑΑΔΕ.

**Μέσα στην εφαρμογή:** μετά το login άνοιξε **Στήσιμο** (`/setup`) για ζωντανό checklist και **Οδηγός** (`/guide`) για αυτό το κείμενο.

| | |
|--|--|
| Βασικό στήσιμο (desk) | **30–60 λεπτά** |
| + Online + Stripe | **+20–30 λεπτά** |
| myDATA / Πελατολόγιο live | Όταν έχεις credentials ΑΑΔΕ |

---

## Τι θα έχεις στο τέλος

| Δυνατότητα | Αποτέλεσμα |
|------------|------------|
| Desk κρατήσεις | Παραλαβή / επιστροφή, μισθωτήριο PDF, φωτό ελέγχου |
| Online booking | Σύνδεσμος `/book/…` για πελάτες 24/7 |
| Stripe | Προκαταβολή με τα **δικά σου** keys (BYOK) |
| ΑΑΔΕ | Ψηφιακό Πελατολόγιο + ΑΠΥ myDATA (ξεκίνα **offline**) |
| Στόλος | CAR / MOTO / SCOOTER / VAN, τιμές, extras, συντήρηση |
| Ομάδα | Υπάλληλοι γκισέ με ρόλους |
| Αναφορές | Έσοδα, utilization, κανάλια |

---

## Βήμα 0 — Προετοιμασία (πριν μπεις στην εφαρμογή)

Μάζεψε:

1. **Εταιρεία:** επωνυμία, ΑΦΜ, ΔΟΥ, άδεια ΠΥΤ (αν υπάρχει).
2. **Καταστήματα:** όνομα, διεύθυνση, πόλη, τηλέφωνο (τουλάχιστον 1).
3. **Στόλος:** πινακίδες, μάρκα/μοντέλο, τύπος, ημερήσια τιμή, εγγύηση.
4. **Λήξεις:** ασφάλεια, ΚΤΕΟ, μηχανολογικός έλεγχος.
5. **Stripe** (για online): Publishable key + Secret key + Webhook signing secret.
6. **ΑΑΔΕ myDATA** (για live αργότερα): User ID + Subscription key από το portal myDATA.
7. **Email επιβεβαιώσεων:** ο διαχειριστής πλατφόρμας πρέπει να έχει `RESEND_API_KEY` στο Vercel (αν δεν έρχονται mail, ρώτα τον).

> **Σημαντικό:** την 1η μέρα άφησε **myDATA** και **Ψηφιακό Πελατολόγιο** σε `offline`. Δοκίμασε παραλαβή → επιστροφή → PDF. Μετά sandbox/live.

## Βήμα 1 — Δημιουργία λογαριασμού

1. Άνοιξε: https://rentfleet-app.vercel.app/register  
2. Συμπλήρωσε:
   - Το **όνομά σου**
   - **Email** (login)
   - **Κωδικό** (≥ 6 χαρακτήρες)
   - **Όνομα εταιρείας** (π.χ. «Aegean Wheels»)
3. Πάτα εγγραφή.

Αυτόματα δημιουργούνται:

- Οργανισμός (η εταιρεία σου)
- Εσύ ως **διαχειριστής**
- Κατάστημα **«Κεντρικό»**
- Μοναδικό **public token** για `/book/…`

Μετά πήγαινε στο **Dashboard**.  
Υπάρχοντες χρήστες: https://rentfleet-app.vercel.app/login

---

## Βήμα 2 — Ζωντανό checklist (`/setup`)

Μετά το login: μενού **Στήσιμο** ή https://rentfleet-app.vercel.app/setup

Βλέπεις πρόοδο % και τι λείπει:

- ΑΦΜ εταιρείας  
- Κατηγορίες  
- Διαθέσιμα οχήματα  
- Extras / τιμές  
- Stripe  
- Δοκιμαστική κράτηση  
- Δημόσιο booking link  
- Λήξεις ασφάλειας/ΚΤΕΟ  

Κάθε γραμμή έχει κουμπί **Ολοκλήρωση** → σε πάει στη σωστή οθόνη.  
Όταν τα **υποχρεωτικά** είναι πράσινα → είσαι έτοιμος για desk.

Πλήρες κείμενο οδηγού: μενού **/guide**.

---

## Βήμα 3 — Καταστήματα (`/branches`)

1. **Καταστήματα** στο μενού.  
2. Επεξεργάσου το «Κεντρικό» ή πρόσθεσε νέα (Αεροδρόμιο, Λιμάνι, πόλη).  
3. Συμπλήρωσε διεύθυνση, πόλη, τηλέφωνο.  
4. **Κωδικός εγκατάστασης ΑΑΔΕ** (`aadeBranchCode`): `0` μέχρι να πάρεις επίσημο κωδικό.

Χρειάζεσαι ≥ **1 ενεργό κατάστημα**.

---

## Βήμα 4 — Κατηγορίες & στόλος (`/fleet`)

### 4.1 Κατηγορίες

| Πεδίο | Παράδειγμα |
|-------|------------|
| Όνομα | Economy, SUV, Scooter 125 |
| Τύπος | CAR / MOTO / SCOOTER / VAN |
| Ημερήσια τιμή | 35 € |
| Εγγύηση | 300–500 € |

### 4.2 Οχήματα

Για κάθε όχημα:

1. Πινακίδα, μάρκα, μοντέλο, έτος  
2. Τύπος + **κατηγορία** + κατάστημα  
3. Χλμ, καύσιμο  
4. Λήξεις: ασφάλεια, ΚΤΕΟ (μηχανολογικός αν ισχύει)  

Καταστάσεις:

| Status | Σημασία |
|--------|---------|
| AVAILABLE | Μπαίνει σε κρατήσεις |
| RENTED | Σε ενοικίαση (αυτόματα στο check-out) |
| MAINTENANCE / BLOCKED | Δεν μπαίνει σε νέες κρατήσεις |
| OUT_OF_SERVICE | Απενεργοποιημένο |

Χρειάζεσαι ≥ **1 AVAILABLE** όχημα με κατηγορία.

---

## Βήμα 5 — Τιμολόγηση & extras (`/pricing`)

1. **Extras:** παιδικό κάθισμα, GPS, 2ος οδηγός — ημερήσια ή flat χρέωση.  
2. **Κανόνες τιμής:** περίοδος (π.χ. Ιούλ–Αύγ) · multiplier `1.3` (= +30%) · προαιρετικά μόνο ΣΚ.

Εμφανίζονται στο desk **και** στο online booking.

---

## Βήμα 6 — ΑΑΔΕ & myDATA (`/tax`) — ξεκίνα offline

1. Μενού **ΑΑΔΕ & myDATA**.  
2. Συμπλήρωσε: ΑΦΜ, ΔΟΥ, ΠΥΤ, σειρά παραστατικών (π.χ. `RF`), ΦΠΑ (**1 = 24%** τυπικά).  
3. Modes στην αρχή:
   - myDATA → **offline**  
   - Πελατολόγιο → **offline**  
4. Όταν έχεις credentials: user id + subscription key → `sandbox` → μετά `live`.

### Τι γίνεται αυτόματα

| Στιγμή | Ενέργεια συστήματος |
|--------|---------------------|
| Check-out (παραλαβή) | Καταγραφή Ψηφιακού Πελατολογίου |
| Check-in (επιστροφή) | Κλείσιμο πελατολογίου + ΑΠΥ 11.2 → myDATA |

Αν **FAILED**: κουμπί **Retry** στη κράτηση ή στο `/tax` (ίδιο ΑΑ, χωρίς νέο αριθμό).  
Στο παραστατικό εμφανίζονται MARK / UID / QR όταν η ΑΑΔΕ απαντήσει σωστά.

---

## Βήμα 7 — Stripe (`/payments`)

1. [Stripe Dashboard](https://dashboard.stripe.com) → Developers → API keys.  
2. Αντίγραψε **Publishable** + **Secret**.  
3. RentFleet → **Πληρωμές** → επικόλληση → Αποθήκευση.  
4. Webhook στο Stripe:
   - Add endpoint  
   - URL = αυτό που δείχνει το `/payments`  
     (`…/api/stripe/webhook/ORG_ID`)  
   - Event: `checkout.session.completed` (τουλάχιστον)  
   - Signing secret `whsec_…` → βάλε το στο RentFleet  

Χωρίς Stripe δουλεύεις μόνο **desk** (πληρωμή εκτός συστήματος).

---

## Βήμα 8 — Δημόσιο online booking

1. Το link βρίσκεται στο `/setup`, `/payments` ή Dashboard:  
   `https://rentfleet-app.vercel.app/book/ΤΟ_TOKEN_ΣΟΥ`  
2. Δοκίμασέ το σε ιδιωτικό παράθυρο.  
3. Βάλ’ το σε site / Google Business / Instagram.

Ροή πελάτη: ημερομηνίες → κατηγορία → extras → στοιχεία → Stripe (αν ενεργό) → επιβεβαίωση (+ email αν Resend είναι ρυθμισμένο).

---

## Βήμα 9 — Πρώτη desk κράτηση (`/bookings/new`)

1. **Νέα κράτηση**  
2. Πελάτης (νέος ή υπάρχων) — ΑΦΜ ή αλλοδαπός + δίπλωμα  
3. Όχημα + ημερομηνίες  
4. Extras / καλύψεις  
5. Αποθήκευση  

Στη σελίδα κράτησης:

1. **Υπογραφή** μισθωτηρίου → **Λήψη PDF** (πραγματικό PDF με ελληνικά)  
2. **Παραλαβή** — χλμ, καύσιμο, φωτό, ζημιές → ΑΑΔΕ  
3. Αργότερα **Επιστροφή** → ΑΑΔΕ + παραστατικό  
4. Gallery φωτό στους ελέγχους  
5. Ακύρωση / no-show / αλλαγή ημερομηνιών-οχήματος **πριν** το check-out  

Email επιβεβαίωσης (αν Resend ON): HTML + συνημμένο PDF μισθωτηρίου.

## Βήμα 10 — Ημερολόγιο, συντήρηση, αναφορές

| Σελίδα | Τι κάνεις |
|--------|-----------|
| `/calendar` | Ποιος έχει τι όχημα τις επόμενες μέρες |
| `/maintenance` | Καταγραφή service/ΚΤΕΟ/ασφάλειας + alerts λήξης (45η) |
| `/reports` | Έσοδα, πληρωμένα, utilization %, κανάλια, top οχήματα (7/30/90η) |
| `/customers` | Αρχείο πελατών |

Βάλε λήξεις στα οχήματα — εμφανίζονται στο `/maintenance` και στο Dashboard.

## Βήμα 11 — Ομάδα υπαλλήλων (`/team`)

Μόνο **διαχειριστής** οργανισμού:

1. **Ομάδα** → νέο μέλος (όνομα, email, κωδικός, ρόλος).  
2. Ρόλοι:

| Ρόλος | Δικαιώματα |
|-------|------------|
| Διαχειριστής | ΑΑΔΕ, Stripe, τιμές, ομάδα, όλα |
| Γκισέ / ops | Κρατήσεις, στόλος, πελάτες, συντήρηση |
| Μόνο ανάγνωση | Προβολή χωρίς εγγραφές |

3. Δώσε στον υπάλληλο το login URL + στοιχεία.

## Βήμα 12 — Καθημερινή λειτουργία

**Πρωί**

1. Dashboard: παραλαβές σήμερα, ΑΑΔΕ εκκρεμή, έσοδα 30η, λήξεις  
2. Calendar: κενά / overlaps  

**Παραλαβή**

1. Κράτηση → PDF + υπογραφή  
2. Check-out + φωτό  
3. ΑΑΔΕ = OK (αλλιώς Retry)  

**Επιστροφή**

1. Check-in + φωτό ζημιών  
2. Παραστατικό στο `/tax`  
3. Όχημα ξανά AVAILABLE (αυτόματα)  

**Εβδομάδα**

1. `/reports`  
2. `/maintenance` — λήξεις

## Λίστα ελέγχου «είμαι live»

- [ ] Εγγραφή + login OK  
- [ ] `/setup` υποχρεωτικά πράσινα  
- [ ] ΑΦΜ + tax offline  
- [ ] ≥1 κατάστημα, ≥1 κατηγορία, ≥1 όχημα AVAILABLE  
- [ ] Desk κράτηση: PDF → check-out → check-in  
- [ ] (Προαιρετικά) Stripe + webhook + δοκιμή `/book/…`  
- [ ] (Προαιρετικά) Extras / season rule  
- [ ] (Προαιρετικά) Υπάλληλος στο `/team`  
- [ ] Λήξεις ασφάλειας/ΚΤΕΟ συμπληρωμένες

## Συχνά προβλήματα

| Πρόβλημα | Λύση |
|----------|------|
| Όχημα μη διαθέσιμο | Σύγκρουση ημερομηνιών ή status ≠ AVAILABLE → `/calendar` |
| Online booking άδειο | Λείπουν κατηγορίες / AVAILABLE οχήματα |
| Stripe error | Λάθος keys ή webhook δεν επιβεβαιώνει |
| myDATA FAILED | Credentials/mode → Retry· κράτα offline μέχρι σταθεροποίηση |
| Πελατολόγιο FAILED (live) | Live API με credentials οργανισμού· μέχρι τότε offline |
| Δεν έρχεται email | `RESEND_API_KEY` στο Vercel (ρώτα διαχειριστή πλατφόρμας) |
| Ξέχασα κωδικό | Reset από διαχειριστή πλατφόρμας |
| «Μόνο διαχειριστής» | Ο ρόλος σου είναι Γκισέ/Viewer — ζήτα αναβάθμιση στο `/team` |
